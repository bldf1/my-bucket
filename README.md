# my-bucket

个人维护的 [Scoop](https://scoop.sh) 软件仓库，通过 GitHub Actions 自动更新清单。

## 使用

```powershell
scoop bucket add my-bucket https://github.com/bldf1/my-bucket
scoop install my-bucket/<软件名>
```
